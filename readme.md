# TechStore — интернет-магазин электроники (Bootstrap)

## Контрольная работа №2
**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Краткое описание проекта
Многостраничный сайт интернет-магазина электроники **TechStore**, разработанный с использованием CSS-фреймворка **Bootstrap 5.3.8**. Проект реализует каталог товаров, страницу товара с характеристиками, форму оформления заказа и модальные окна. Предметная область соответствует контрольной работе №1, но реализация выполнена полностью на Bootstrap с собственными доработками в `custom.css`.

## Используемый фреймворк
**Bootstrap 5.3.8** (https://getbootstrap.com/)

## Способ подключения Bootstrap
В проекте Bootstrap подключён **локально** (без использования CDN). Файлы фреймворка размещены в папке `vendor/bootstrap/`.

Используются:
- `vendor/bootstrap/css/bootstrap.min.css` — минифицированная версия стилей.
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JS Bundle, включающий Bootstrap JS и Popper.js (необходим для работы navbar, modal, accordion, toast).


Файл custom.css подключается строго после Bootstrap для корректного переопределения стилей.

Реализованные Bootstrap-компоненты
Сетка: container, row, col-*, col-md-*, col-lg-*, g-*
Навигация: navbar (с адаптивным мобильным меню)
Карточки: card, card-body, card-img-top
Кнопки: btn, btn-primary, btn-outline-secondary, btn-lg
Формы: form-control, form-select, input-group, form-check, form-floating
Модальное окно: modal, modal-dialog, modal-content
Сообщения: alert (информационные блоки и закрытие по крестику)
Значки: badge (метки "Хит", "Новинка", "-20%")
Дополнительные компоненты: accordion (в фильтрах каталога), toast (уведомление об успешном заказе), breadcrumb (хлебные крошки), table (striped, hover, bordered).
Самостоятельные доработки (для повышенной оценки)
Локальное подключение Bootstrap (+0.5 балла): файлы фреймворка размещены в vendor/, что демонстрирует понимание структуры зависимостей и позволяет работать без интернета.
Дополнительные компоненты (+0.4 балла): реализован accordion для компактного отображения фильтров и toast для уведомления об успешном оформлении заказа.
Улучшенный пользовательский сценарий заявки (+0.4 балла): добавлен динамический пересчёт итоговой суммы при выборе товара и изменении количества, а также кнопки "+" и "−" для управления количеством.
Визуальная целостность через custom.css (+0.3 балла): добавлены плавные hover-эффекты для карточек, кастомный градиент для шапки формы, стили для валидации полей и прижатый к низу footer (min-vh-100 + mt-auto).
Адаптивность (+0.3 балла): корректное перестроение сетки на мобильных устройствах (использование col-12, col-md-6, col-lg-4 и g-* для отступов).
Подробная документация (+0.2 балла): данный README содержит полную инструкцию по запуску и проверке проекта.
